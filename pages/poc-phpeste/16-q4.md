# Por baixo do capô: <em>cada módulo é um pacote</em>.

::before::

<p class="ph-file-label">composer.json</p>

```json {3,8-10}
{
  "require": {
    "internachi/modular": "^3.0",
    "shop/payment": "*",
    "shop/checkout": "*",
    "shop/gateway": "*"
  },
  "repositories": [
    { "type": "path", "url": "app-modules/*" }
  ]
}
```

<p class="ph-callout">O Composer trata cada pasta de <code>app-modules/*</code> como <strong>pacote local</strong>.</p>

::after::

<p class="ph-file-label">app-modules/payment/composer.json</p>

```json {6-12}
{
  "name": "shop/payment",
  "autoload": {
    "psr-4": { "Shop\\Payment\\": "src/" }
  },
  "extra": {
    "laravel": {
      "providers": [
        "Shop\\Payment\\PaymentServiceProvider"
      ]
    }
  }
}
```

<p class="ph-callout ph-callout--ok"><strong>Package discovery</strong> do Laravel registra o provider sozinho.</p>

::footer::

<p class="ph-rule-text" v-click="1">Composer carrega. Laravel auto-descobre. Você nunca mais toca em providers.php.</p>
